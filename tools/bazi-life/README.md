# 命盤人生・排盤引擎（第 0 步）

「命盤人生」要用八字命盤推動一整段人生模擬。第一步先把命盤排準：輸入出生時間和地點，把時間校正到正確的時刻，再排出四柱、藏干、十神、納音、大運和流年。每一步怎麼換算的都會列出來，讓人可以逐項核對。

- 預覽（Claude Artifact）：https://claude.ai/artifact/3a3ezBHmLKeKBxGaNveAV2
- 研究摘要與開發規畫：https://claude.ai/code/artifact/9dc96cc1-73a1-46db-a40e-3dac666a6987

這個資料夾是獨立專案，沒有和 `tools/pet-life` 共用任何程式。

## 怎麼排才準

| 柱 | 用哪一個時間 | 原因 |
| --- | --- | --- |
| 年柱、月柱、起運 | 出生的**精確時刻**，換成東八區時間後和節氣比對 | 節氣是天文上的一個瞬間，全世界同時發生；節氣表以東八區計時 |
| 日柱、時柱 | 出生地的**真太陽時**（世界時＋經度×4 分鐘＋均時差） | 一天和時辰是看太陽在當地的位置 |

時間校正會自動處理：

- 歷史時區：臺灣 1937-10-01 到 1945-09-21 使用 UTC+9。
- 日光節約時間：臺灣 1946–1961、1974–1975、1979 年，中國 1986–1991 年，以及世界各地的夏令時間。
- 有問題的時間：時鐘撥回而出現兩次的時間（例如 1979-09-30 23:30）可以選第幾次；時鐘撥快而不存在的時間（例如 1979-07-01 00:30）會當成標準時間計算。
- 地方平時：標準時間實施之前用地方平時（例如臺北 1896 年以前是 UTC+8:06）。

以上都依照瀏覽器內建的 IANA 時區資料。

可以調整的設定：

- 日柱、時柱用的時間：真太陽時（預設）、平太陽時、不校正。
- 子時規則：23 點換日（預設），或夜子時（23–24 點日柱算當天）。
- 起運算法：精確（3 天折 1 年，算到分鐘，預設）、元亨利貞、傳統按時辰、傳統算到小時。

不知道出生時辰時，只排年、月、日三柱，起運以中午 12 點估算。如果那天剛好交節，會說明交節前後月柱分別是什麼。

## 驗證

`npm test` 一共 32 項，大約 3 秒跑完：

- **節氣：** tyme4ts（壽星天文曆演算法）算出的 1900–2100 年每一個「節」（共 2,412 個），和獨立星曆 astronomy-engine 比對。最大差 62 秒，測試門檻 90 秒。
- **四柱：** 不用 tyme4ts，改用 astronomy-engine 的節氣時刻加上教科書規則，重算 2,000 個隨機時刻的四柱，結果和引擎完全一致。使用的規則是立春換年、五虎遁、儒略日、五鼠遁。另外用 5,000 個時刻跑過一次，也全部一致。
- **均時差：** 和 astronomy-engine 算出的太陽時角相比，1900–2100 年內誤差在 5 秒以內。
- **臺灣時間史：** 戰時時間、歷年日光節約時間、重複與不存在的時間、地方平時。
- **已知盤例：**
  - 1988-02-15 23:30：早子時為辛丑日戊子時，夜子時為庚子日。
  - 2024 立春 16:27 前後換年。
  - 1979 年夏令時間的時柱。
  - 烏魯木齊用北京時間時，太陽時差 2 小時 11 分。
  - 紐約出生。
  - 1988 年男命 6 年 2 個月 26 天起運。

`test/page.e2e.mjs` 用瀏覽器檢查預覽頁，共 16 項：每個範例、夜子時切換、重複時間的選擇、自訂經緯度、大運流年，以及手機寬度不會左右捲動。

研究文件的第 0 步門檻還差一項：和 JPL 星曆及壽星網頁版比對。這個開發環境連不到那兩個網站，需要在能上網的地方抽查。

## 檔案

| 路徑 | 說明 |
| --- | --- |
| `src/core/time.js` | 出生地的鐘錶時間 ⇄ 世界時：日光節約時間、戰時時間、重複或不存在的時間 |
| `src/core/solar.js` | 均時差（NOAA／Meeus 公式）、平太陽時、真太陽時 |
| `src/core/chart.js` | 排盤：`computeChart()` 產生完整命盤，`fourPillars()` 只回傳四柱（給大量比較用） |
| `src/core/places.js` | 出生地：臺灣各縣市與主要鄉鎮、港澳、中國大陸、海外主要城市。其他地點可以自訂經緯度 |
| `src/core/zh.js` | tyme4ts 用簡體字命名，這裡轉成繁體 |
| `src/page.html`、`src/app.js` | 預覽網頁 |
| `scripts/build.mjs` | 產生 `public/index.html`（內含 tyme4ts，任何靜態網站都能直接放）；加上 `--fragment <檔案>` 會另外產生 Artifact 用的版本，tyme4ts 從 unpkg 載入 |
| `public/index.html` | 產生出來的網頁，有提交進 git |
| `test/*.test.js` | 單元測試（`npm test`） |
| `test/page.e2e.mjs` | 瀏覽器測試 |

## 開發

```bash
cd tools/bazi-life
npm install
npm test
npm run build
PLAYWRIGHT=$(npm root -g)/playwright CHROMIUM=/path/to/chrome node test/page.e2e.mjs
```

改完 `src/` 之後要跑 `npm run build`，再把 `public/index.html` 一起提交。

## 用到的套件

- [tyme4ts](https://github.com/6tail/tyme4ts) 1.5.2（MIT）：節氣、干支、藏干、十神、納音、起運、大運。
- astronomy-engine 2.1.19（MIT）：只用在測試，當作獨立的星曆比對。
- esbuild（MIT）：只用在建置。
