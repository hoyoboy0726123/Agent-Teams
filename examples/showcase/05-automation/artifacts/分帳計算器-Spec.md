# 朋友出遊分帳計算器 — 產品規格

## 1. 問題陳述
朋友出遊時常有多筆花費由不同人代墊、不同人分攤，手動計算「誰該轉錢給誰」容易出錯且轉帳次數多。
本工具讓使用者快速建立成員與支出紀錄，自動算出**最少轉帳次數**的結算方案，支援手機瀏覽與列印。

## 2. 目標使用者
- 主要：規劃出遊/聚餐的發起人，用手機臨時建立分帳
- 次要：旅行結束後回顧結算、需要列印/截圖給群組看的人
- 使用情境：多為 2–10 人小團體，單次使用（不需帳號登入）

## 3. 使用者故事與驗收標準

### US1：新增/管理成員
作為使用者，我要新增出遊成員名單，以便後續指定付款人與分攤人。
- AC：可新增、編輯、刪除成員（姓名文字輸入）
- AC：成員名稱不可為空、不可重複
- AC：刪除已被支出引用的成員時要提示（該支出會受影響）

### US2：新增/管理支出
作為使用者，我要記錄每筆花費（項目、金額、誰付的、誰分攤），以便計算結算。
- AC：欄位：項目名稱（選填）、金額（必填，NTD 整數，>0）、付款人（單選，必填）、分攤人（多選，必填，預設全選）
- AC：分攤方式支援「均分」；可選填自訂分攤比例/金額（v1 可先做均分，比例分攤列為 nice-to-have）
- AC：可編輯、刪除已新增的支出
- AC：支出列表顯示總金額加總

### US3：自動結算（最少轉帳次數）
作為使用者，我要看到系統算好「誰該付給誰多少錢」，且轉帳筆數最少。
- AC：計算每人淨額（已付 − 應分攤），正值代表應收、負值代表應付
- AC：使用貪婪演算法（最大應收 vs 最大應付互抵）產生轉帳建議，逼近最少交易數
- AC：金額四捨五入到整數元（NTD 無小數常態），並處理因四捨五入產生的 ±1 元誤差不遺漏、總和仍平衡
- AC：結果顯示每筆「A 付給 B：NT$ 金額」

### US4：手機好用
- AC：單欄式版面，觸控友善（按鈕/輸入框最小點擊區 44px）
- AC：金額輸入使用數字鍵盤（inputmode="numeric"）
- AC：支出多的情況可捲動瀏覽，不需切頁

### US5：列印結果
- AC：提供「列印」按鈕，產出乾淨版面：成員清單、支出明細、結算結果（隱藏輸入框/按鈕等操作元件）
- AC：使用瀏覽器列印（CSS `@media print`），支援 A4

## 4. 版面配置（單頁式，由上而下）
1. **標題列**：分帳計算器（NT$）
2. **成員區塊**：輸入框 + 新增按鈕；已新增成員以標籤(chip)列出，可刪除
3. **支出區塊**：
   - 新增支出表單（項目、金額、付款人下拉、分攤人核取方塊群）
   - 支出列表（卡片式，顯示金額/付款人/分攤人，含編輯/刪除）
4. **結算結果區塊**：
   - 每人淨額摘要（應收/應付）
   - 建議轉帳清單
   - 「列印結果」按鈕
5. Sticky 底部或浮動按鈕：新增支出（手機上方便操作）

## 5. Edge Cases
- 成員少於 2 人：無法計算分帳，顯示提示訊息
- 尚未新增任何支出：結算區顯示「目前尚無支出」
- 支出的分攤人清單中包含已被刪除的成員：需同步移除或提示
- 金額含小數：NTD 一般不用分，強制整數；若需支援分再列為未來需求
- 四捨五入誤差：確保結算後總轉入=總轉出（尾差分配給金額最大或第一位應付者）
- 單一成員同時是所有支出付款人（沒人欠他/她之外）：應顯示「不需轉帳」
- 已結清（淨額為0）：不出現在轉帳建議中
- 支出金額為 0 或負數：輸入驗證擋掉
- 使用者重新整理頁面：v1 可先用 localStorage 暫存，避免資料遺失（不需登入/雲端）
- 列印時內容過長：確保分頁不切斷單一支出卡片（CSS page-break）

## 6. 非目標（v1 不做）
- 帳號系統、雲端同步、多裝置共享
- 多幣別（僅新台幣）
- 比例式/加權分攤（先做均分，列為 Fast Follow）
- 匯出 Excel/CSV（先用列印/截圖取代）

## 7. 成功指標
- 完成一次「新增成員→新增支出→看到結算結果」的任務完成率 > 90%
- 從開啟頁面到取得結算結果的平均時間 < 3 分鐘
- 手機裝置使用佔比與跳出率（若手機跳出率明顯高於桌面，需檢視版面）
